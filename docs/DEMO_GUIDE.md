## 1. Overview
The AeroCadastre Synthetic Demo provides a complete, deterministic, zero-network walkthrough of the 11-stage cadastral boundary extraction pipeline. It runs on controlled geometric fixtures located at `tests/fixtures/synthetic_cadastral/`.

---

## 3. Generated Demo Artifacts

1. **`demo_manifest.json`**:
   Comprehensive JSON manifest recording pipeline run ID, timestamps, step status, and audit parameters.
2. **`field_route_plan.json`**:
   The optimized surveyor inspection route visiting candidate parcels in nearest-neighbor priority order.
3. **`copilot_explanations.json`**:
   Audit-safe explanations generated by the Cadastral Copilot for each candidate parcel.
4. **`SYNTH_QUAD_SCENE_01/candidate_parcels.geojson`**:
   GeoJSON feature collection containing the inferred candidate parcel polygons in `EPSG:32643` with `NOT_ASSIGNED_PRE_CADASTRE` ULPIN status.
